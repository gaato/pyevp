Email Verification Protocol · Python

Verify email addresses without sending an email

With the Email Verification Protocol, the browser brings a token signed by the user's email provider. PyEVP verifies it on your Python server: no confirmation email, no code to copy.

Try the demo Read the docs

How it works

  1. 1

    The browser asks

    The browser asks the user's email provider for a token.

  2. 2

    The provider vouches

    The provider vouches for the email address by signing the token.

  3. 3

    Your server verifies

    Your server verifies the token with PyEVP.

See the compatibility guide for browser support and deployment requirements.
